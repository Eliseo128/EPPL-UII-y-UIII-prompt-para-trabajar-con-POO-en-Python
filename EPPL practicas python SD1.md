**🟣 Prácticas Guiadas (docente conduce)**
- **ARIA — El chatbot que saluda**: variables, f-strings, input/output
- **Calculadora Inteligente**: todos los operadores con "razonamiento"
- **Detector de Temperatura IA**: pseudocódigo → Python, diagrama de flujo

**🔵 Prácticas Supervisadas (alumno trabaja, docente observa)**
- **Generador de Personaje RPG**: variables + tipos + primer commit a GitHub
- **Clasificador de Emociones IA**: lógica secuencial + operadores relacionales

**🟠 Prácticas Autónomas (alumno independiente)**
- **Sistema de Triaje Médico IA**: proyecto integrador con todos los temas
- **Crea tu Asistente IA**: plantilla libre para que el alumno elija su propio contexto

Cada práctica incluye objetivo, pasos de ejecución, código funcional con resaltado, salida esperada y un botón para profundizar el tema. Todos los ejemplos "simulan IA" con lógica que los alumnos pueden entender y modificar, sin salirse del nivel de la unidad.
