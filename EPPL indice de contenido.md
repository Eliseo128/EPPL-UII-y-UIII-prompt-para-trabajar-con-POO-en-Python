# Módulo I – Submódulo 2

**Duración total:** 128 horas
**Lenguaje de programación:** Python
**Herramientas:** Visual Studio Code, Git y GitHub

# Competencias a desarrollar

* Diseñar algoritmos para resolver problemas mediante programación lógica.
* Elaborar proyectos básicos utilizando Python.
* Aplicar estructuras de control y colecciones de datos.
* Implementar funciones y fundamentos de programación orientada a objetos.
* Utilizar herramientas de desarrollo profesional como Visual Studio Code, Git y GitHub.
* Documentar y presentar proyectos tecnológicos con lenguaje técnico.
* Aplicar pensamiento lógico, trabajo colaborativo y resolución de problemas.
