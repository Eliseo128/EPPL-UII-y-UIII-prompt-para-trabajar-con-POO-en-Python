# 🧪 Evaluación Práctica de Programación Orientada a Objetos en Python

## 🎯 Objetivo

Evaluar la capacidad del alumno para:

* Definir clases correctamente
* Modelar atributos y métodos
* Implementar interacción con el usuario
* Crear y manipular objetos
* Organizar lógica básica orientada a objetos

---

## ⏱️ Duración sugerida

* Examen: 2 a 3 horas
* Proyecto final: 1 a 2 semanas

---

# 📘 Estructura de la Evaluación

## 🔹 Parte 1: Nivel Básico (30%)

**Instrucción:**
Selecciona **3 ejercicios** del listado (1–20).

**Requisitos:**

* Definir la clase correctamente
* Declarar 3 atributos
* Implementar funciones:

  * leerdatos()
  * mostrardatos()
* Crear 2 objetos
* Entrada de datos interactiva

**Criterio clave:**
Comprensión de estructura de clase y sintaxis

---

## 🔹 Parte 2: Nivel Intermedio (30%)

**Instrucción:**
Selecciona **2 ejercicios** del listado (21–40).

**Requisitos adicionales:**

* Validar al menos 1 dato (ejemplo: edad > 0, precio > 0)
* Agregar 1 método extra (ejemplo: calcular, comparar, actualizar)
* Mostrar resultados con formato claro

**Criterio clave:**
Lógica y control de datos

---

## 🔹 Parte 3: Nivel Avanzado (40%)

**Instrucción:**
Selecciona **1 ejercicio** del listado (41–60) y conviértelo en un mini sistema.

**Requisitos obligatorios:**

* Menú interactivo (tipo consola), por ejemplo:

  1. Registrar datos
  2. Mostrar datos
  3. Modificar datos
  4. Salir
* Uso de múltiples objetos (mínimo 3)
* Almacenamiento en estructura (lista)
* Uso de ciclo (while)

**Criterio clave:**
Integración de conceptos y flujo de programa

---

# 🧩 Proyecto Final (Alternativa al Examen)

## 🏗️ Opción recomendada: Sistema Integrado

**Instrucción:**
Combinar mínimo **3 clases relacionadas**, por ejemplo:

* Cliente + Pedido + Producto
* Alumno + Materia + Calificación
* Paciente + Doctor + CitaMedica

---

## 🔧 Requisitos del proyecto

* Mínimo 3 clases
* Relación lógica entre clases
* Menú general
* Funcionalidades mínimas:

  * Registrar
  * Mostrar
  * Buscar
* Uso de listas para almacenamiento
* Interacción completa con el usuario

---

## 🧠 Criterios de logro

* **90–100:** Dominio completo, estructura clara y funcional
* **80–89:** Buen manejo con pequeños errores
* **70–79:** Cumple lo básico, lógica limitada
* **<70:** Deficiencias en estructura o ejecución
